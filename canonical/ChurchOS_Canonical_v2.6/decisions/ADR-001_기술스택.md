# ADR-001 ChurchOS 기술 기준
상태: DESIGN_SELECTION; 설치 버전·실행 호환성 NOT_RUN.

ChurchOS 앱은 Flutter로 교인·목회자·관리자 화면을 제공한다. 서버는 기존 ZIP의 TypeScript·NestJS·Fastify, PostgreSQL 16, 명시적 SQL·repository 구조를 설계 선택으로 유지한다. API·Worker·Scheduler만 ChurchOS 코드베이스를 공유한다. 테스트는 서버 단위·계약·DB 통합·앱·실기기를 포함한다.

다른 여섯 제품의 언어·프레임워크는 각 제품에서 결정한다. API 계약만 맞추며 ChurchOS 스택을 강제하지 않는다. 정확한 도구 버전은 구현 착수 시 공식 호환성과 잠금파일로 확정한다. 관리자 웹·PWA 구현 의존성은 현재 범위에서 제외한다.
