이 지시는 이전 통합 앱·공동 제품 코드·웹 중심 계획보다 우선한다. 일곱 제품은 각각 독립 저장소, 도메인 모델, 데이터 소유권, 테스트, 버전, 배포 단위를 가진다. 서버 대수는 제품 독립성과 별개다. 같은 물리 서버에서도 제품별 프로세스·DB 권한·비밀·백업을 분리한다.

현재 정본은 ChurchOS만 소유한다. 다른 여섯 제품의 내부 설계·정본·암호화 정책을 이 패키지로 변경하지 않는다. 공통 인증 기반은 교체 가능한 내부 인프라이며 별도 사용자 앱이 아니다. 통합 로그인은 목표이지만 각 서비스의 토큰 audience·scope와 별도 동의 검증은 유지한다.

원본 ZIP과 기존 Git 이력은 보존했다. 삭제란 이번 활성 정본 패키지에서 과거·중복·충돌 문서를 제외한 것을 뜻한다. 개별 Library 파일이나 Git 원본은 삭제하지 않았다. 세부 제외 목록은 reports/file_changes.csv를 따른다.
