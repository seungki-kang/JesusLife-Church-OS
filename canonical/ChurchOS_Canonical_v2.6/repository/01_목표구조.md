# 저장소 기준
ChurchOS 저장소에는 ChurchOS 앱·서버·DB·API 소비 계약만 둔다. 타 제품 소스·원문 DB·전문 온톨로지를 복사하지 않는다.

- apps/church-app: Flutter 역할별 화면
- services/church-core: API·Worker·Scheduler
- api/openapi: ChurchOS API 정본
- events: ChurchOS 이벤트 정본
- contracts: 제공자별 소비 계약
- db/migrations: 변경 불가 적용 이력과 후속 migration
- db/security-tests: 합성 데이터 격리 검사
- specs·ux·architecture·decisions: 설계 정본
- tools·tests·.github: 검증·회귀·자동 검사

간소화 브랜치: main → 작업 브랜치 → PR → 검사 → 병합. 현재 ZIP은 정본 설계 패키지이며 Git 저장소를 덮어쓰는 설치 스크립트가 아니다.
