# 제품 정의와 소유권 — 정본 v2.0

ChurchOS는 교인이 매일 교회 생활을 시작하고 목회자·관리자가 교회 업무를 처리하는 중심 앱이다. 초기 출시는 Flutter 앱으로 통일하고 역할별 화면을 제공한다. 관리자 웹·PWA·Headless 배포 제품은 현재 범위에서 제외한다. API 제공은 유지한다.

| 독립 제품 | 정본 소유 데이터·책임 | ChurchOS 연결 |
|---|---|---|
| ChurchOS | 교회·소속·역할·공동체·일정·출석·공지·돌봄 업무·봉사·브랜드·감사 | 앱 시작·교회 운영 중심 |
| 너랑나랑 | 관계 문답·세션·참여자·서명·은혜 기록 | 허용된 초대·진행 상태·앱 열기 |
| 생명일기 | 7문항·회차·개인 원문·개인 공유 정책 | 사용자 요청 일회용 앱 열기만; 작성 상태 수신 금지 |
| JLPrayer | 기도수첩·기도방·중보·응답·공개범위 | 공개 캠페인·허용 요약·앱 열기 |
| JLBible | 본문 라이선스·통독계획·진도·성경 온톨로지 | 오늘 읽기·허용 진도·앱 열기 |
| JLAcademy | 교육과정·강좌·수강·학습·수료 | 강좌 요약·사용자 동의 수강 상태·학습 이어가기 |
| CHGO | 성장 온톨로지·동의된 근거·해석·집계 | 최소 10명 공동체 집계; 억제·coverage 필수 |

전문 앱은 ChurchOS 없이도 자체 로그인·핵심 기능을 운영한다. ChurchOS가 앱을 연결해도 전문 기능의 소유권은 이동하지 않는다. ChurchOS 교육 행사 일정·출석은 운영 데이터이고 교육과정·학습·수료 정본은 JLAcademy에 둔다.

지저스라이프 원은 사용자 화면에 드러내지 않는다. ChurchOS 최종 브랜드명은 추후 결정하며 교회별 로고·색·앱 표시명은 설정으로 제공한다.

## 불변조건
- 타 제품 DB 직접 조회·공유 테이블·제품 간 SQL join 금지
- membership != vault_ownership; participation != growth; completion != maturity; missing != zero
- 교회 관리자 권한이 개인 일기·기도·관계 원문 접근권을 만들지 않음
- CHGO 개인 점수·영적 서열·개인 인사이트의 ChurchOS 수신 금지
- 공통 인증과 제품별·목적별 동의 및 교회 소속 권한을 분리
- 외부 장애가 교인 등록·일정 저장·출석 같은 핵심 업무를 막지 않음
- 원문·토큰·비밀은 이벤트·로그·캐시에 복제하지 않음

## 마케팅에 필요한 출시 가치
교회 개설→브랜드 적용→교인 초대→공지·일정 게시→출석·후속 업무의 흐름을 먼저 완성한다. 전문 앱 연결은 필요에 따라 활성화한다. 설치·가입·교회 가입 승인·첫 행동 성공률과 관리자의 업무 시간을 측정한다. 활동량을 영적 성장으로 홍보하지 않는다.
