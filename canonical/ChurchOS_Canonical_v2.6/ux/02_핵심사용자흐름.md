# 핵심 앱 흐름
1. 교회 브랜드/ChurchOS 스플래시→로그인→교회 선택·가입 승인→Today.
2. Today는 오늘 일정·공지·공동체·봉사 행동을 먼저 보여준다.
3. 연결 메뉴에서 여섯 전문 제품을 발견하고 목적·공개 범위를 확인해 연결한다.
4. 생명일기는 상태를 조회하지 않고 사용자가 누르면 단회 handoff로 연다.
5. 전문 앱은 자체 화면에서 전문 기능을 수행하고 안전한 앱 링크로 ChurchOS에 복귀한다.
6. 목회자·관리자는 동일 앱에서 역할에 맞는 교인·업무·브랜드·감사 화면을 사용한다.
7. 교회 전환·탈퇴 시 권한·캐시를 제거하고 다음 교회 범위에서 다시 로딩한다. 개인 전문 제품 계정의 소유권은 유지한다.
8. 외부 장애 시 ChurchOS 핵심 화면은 사용 가능하며 실패한 연결만 재시도한다.

첫 교회 개설·초대·공지 게시·체크인·후속 업무를 파일럿 핵심 시나리오로 측정한다. 최종 앱 이름은 미정이다.
