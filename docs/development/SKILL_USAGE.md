# ChurchOS 스킬 적용 단계와 종류

2026-10-24. 사용자의 '스킬 쓰는 단계와 종류를 기억하고 grill-with-docs 반영' 요청을 저장소의 지속 지침으로 기록한다. AGENTS.md와 이 문서를 새 세션에서 읽어 적용한다. 계정 전체의 모든 대화가 자동으로 이 내용을 기억한다고 주장하지 않는다.

## grill-with-docs 운영 방식

명령 예: `$grill-with-docs 교회 가입 승인과 역할을 검토하고 문서에 반영해줘`.

기본 한 주제·한 질문씩 진행하고 필요할 때만 최대 세 독립 질문을 묶는다. 코드·문서로 답할 수 있는 사실은 먼저 조사한다. 이미 합의한 기본 방향을 반복 질문하지 않는다. 새 선택에는 권장안·이유·대안을 제시하고 답을 기다린다. 답이 없는 것은 OPEN으로 남긴다.

용어는 GLOSSARY.md, 일반 결정은 docs/decisions/DESIGN_DECISIONS.md에 기록한다. 장기 영향이 큰 실제 절충만 별도 ADR로 만든다. 업무 규칙과 구현 세부사항은 운영/상세 설계·기능표·계약표에 반영한다. 원본 정본과 상태를 보존하고 코드를 구현하지 않았으면 명시한다.

이번 스킬은 Matt Pocock 원본의 grilling + domain-modeling 취지를 ChurchOS에 맞춰 자체 실행 가능하게 재구성한 버전이다. 원본 전체 설치가 아니며 다른 스킬 호출 도구를 요구하지 않는다. 원본 출처는 스킬 references에 기록했다. 설치·공유는 현재 설치 방식 한 가지를 선택하고 중복 사본이나 자동 upstream 갱신으로 프로젝트 규칙이 덮어써지지 않게 한다.

## 실행 상태

스킬 파일 구조·YAML·프로젝트 참조를 검사한다. 정적 검증 성공을 실제 인터뷰 행동 검증이나 PC 설치 완료로 쓰지 않는다. 이번에는 스킬 제작/도입 작업만 수행하며 실제 가입·권한 인터뷰는 다음 명시 요청에서 시작한다. GitHub main 반영과 사용자 PC 설치는 별도 상태로 안내한다.
