# 공통 신학적 서비스 이용 기준 문구 초안

2026-10-24. 문서 ID COS-CRITERIA-DRAFT-001. 상태 AGREED / DESIGN (사용자 검토 초안 문구·운영 채택 전). 이번 문서는 외부 교단의 신앙고백을 인용한 것이 아니라 COS-CHURCH-025의 다섯 핵심 항목과 COS-CHURCH-030의 성령 사역 추가를 반영한 검토 초안이다. CT-01~05는 COS-CHURCH-029, CT-06은 COS-CHURCH-030에서 사용자 검토 초안 문구로 합의(AGREED)했다. 전체 기준의 운영 채택은 아직 아니다. 문구의 사용자 검토 초안 합의는 COS-CHURCH-029/030에 기록했으며 실제 해석/근거 검토와 운영 채택은 별도다. 운영 채택 버전·시행일·실제 신학 검토자·정책 승인 이력은 아직 없다. 구현·실행 검증 NOT_RUN.

## 사용자 검토 초안으로 합의한 문구

| 항목 ID | 초안 범위 | 문구(CT-01~06 사용자 검토 초안 AGREED·운영 채택 전) |
|---|---|---|
| CT-01 | 성경의 신앙 기준으로서 권위 | 우리는 성경을 기독교 신앙과 삶의 기준으로 받아들입니다. |
| CT-02 | 삼위일체 | 우리는 성부·성자·성령의 삼위일체 하나님을 믿습니다. |
| CT-03 | 그리스도의 참 하나님·참 인간 되심 | 우리는 예수 그리스도께서 참 하나님이시며 참 인간이심을 믿습니다. |
| CT-04 | 십자가와 부활 | 우리는 예수 그리스도께서 십자가에서 죽으시고 부활하셨음을 믿습니다. |
| CT-05 | 그리스도를 통한 은혜의 구원 | 우리는 구원이 예수 그리스도를 통해 주어지는 하나님의 은혜임을 믿습니다. |
| CT-06 | 성령의 내주·진리 깨달음·거룩한 삶과 복음 증언을 위한 인도와 능력 | 우리는 성령께서 우리 안에 거하시며, 진리를 깨닫게 하시고, 거룩한 삶과 복음의 증언을 위해 우리를 인도하시고 능력을 주심을 믿습니다. |

신청 목회자 개인의 기준 동의와 신청 교회가 같은 기준을 고백한다는 대표·위임 권한에 따른 확인을 별도 항목으로 받는다. 개인 동의만으로 교회의 고백을 검증 완료로 보지 않고 지정 신학 검토자가 교회 공식 신앙고백·정관·소속 교단 자료 등 확인 가능한 근거를 검토한다. 교회 자료가 없거나 선언 주체·권한이 불명확하면 추가 확인 대기로 두고 진술·체크만으로 승인하지 않는다. 교인 개인의 동의나 기도·일기 기록은 요구하지 않는다. 근거: [COS-CHURCH-031](../../decisions/DESIGN_DECISIONS.md#cos-church-031). 여섯 문구를 유지하되 개인 동의와 교회 확인의 화면·기록 주체를 분리한다. 교회를 대표해 선언할 수 있는 위임 범위의 구체 증빙·필수 자료·질의 절차는 미결이다.

## 유지할 적용 경계

- 문구 초안은 개설을 신청하는 교회·목회자의 서비스 이용 기준 검토용이며 일반 교인 가입 심사에 추가하지 않는다.
- 세례 방식·교회 정치·은사 이해·예전의 차이 자체를 일률적 거절 사유로 삼지 않는다. 이는 모든 차이가 심사와 무관하다는 선언이 아니며 핵심 항목과 충돌한다는 판단에는 채택된 해석 범위와 근거가 필요하다.
- 성령의 사역을 별도 항목으로 명시하되 특정 은사의 형태·특정 체험을 모든 신청자의 필수 이용 조건으로 정하지 않는다(COS-CHURCH-030). 삼위일체 항목의 성령 언급과 별개로 적용하며 개인 기도/일기/활동을 증명 자료로 수집하지 않는 기존 경계를 유지한다.
- AI·CHGO의 이단 자동 판정·자동 승인/거절을 금지한다. 신학 검토와 최종 결정은 다른 사람이 맡는다.
- 허용 교단 등재나 본인 동의만으로 승인하지 않는다. 교회 실재·재직/자격·대표 권한과 제출 자료 확인을 구분한다.
- 후보 교단이나 특정 교회가 이 문구에 동의하거나 위반한다고 문서 작성자가 임의 판정하지 않는다.
- 접수 시 안내된 채택 기준/목록 버전을 최초 심사와 그 결정의 재검토에 유지하고 새 기준 요청은 본인 명시 요청으로 구분한다.

## 채택 전 남은 일

여섯 항목 사용자 문구 검토는 합의했다. 지정 신학 검토 책임자의 해석 범위·판단 근거 제안, 다른 서비스 정책 책임자의 채택/버전/시행일 승인, 개인/교회 별도 확인의 동의 안내·위임 증빙·질의 경로와 보완/이의신청의 연결이 남아 있다. 실제 사례 대조·자료 검증은 NOT_RUN이다. 문구 동의와 실제 운영 채택/배포를 구분한다.
