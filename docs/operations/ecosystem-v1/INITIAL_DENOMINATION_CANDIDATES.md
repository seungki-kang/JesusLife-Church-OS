## 명칭·범위 원칙

후보 ID는 이번 설계의 참조용이며 기존 정본 교단 ID를 대체하거나 DB에 배포하지 않는다. 명칭 유사성·약칭·'순복음' 표현만으로 다른 총회를 포함하지 않는다. 회원 교회와 목회자의 개인 자격·선교단체 회원 관계는 서로 같다고 가정하지 않는다. KAICAM을 교단과 동일한 조직 구조로 간주하거나 소속 교회가 아닌 모든 독립교회로 범위를 확대하지 않는다. KAICAM 교회 소속 확인 대응 경로는 COS-CHURCH-023으로 확정했다. 실제 발급 자료의 종류·확인 목적을 검토해야 하며 교회 소속 근거 부족 시 독립교회 대체 자료로 보완한다.

모든 후보에 대해 발급 주체·공식 확인 경로·실제 소속·목회자 재직/자격·대표 권한·플랫폼 이용 기준을 사람 심사하며 자동 승인하지 않는다. 자료가 미확인인 항목은 NOT_VERIFIED로 유지한다. 위 명단은 이단 판정 명부가 아니며 미등재 대상의 예외 심사 가능성을 유지한다.

2026-10-24 웹 열람 기준. 이는 명칭·기관 식별 자료이며 신학적 적합성 또는 모든 증명서의 진위를 확인한 결과가 아니다.

- [기독교대한하나님의성회 기하성총회](https://www.kihasung.org/), [기독교대한하나님의성회 광화문](https://www.khs1953.com/): 유사 명칭의 공식 사이트가 있어 사용자 의도에 맞는 총회별 범위 확정이 필요함. 이 두 기관을 자동 등재하거나 이것이 전체 총회 목록이라고 단정하지 않음.

그 밖의 후보는 사용자 제시 명칭만 기록했으며 공식 자료 확인을 완료했다고 쓰지 않는다. 실제 목회자/교회의 자격·소속 확인, 목록 정책 채택, 구현·실행 검증은 NOT_RUN.

## 기하성 후보 범위 후속 확정

사용자가 https://www.agk.or.kr/ 를 직접 지정해 CD-CAND-013은 이 공식 사이트로 식별되는 기독교대한하나님의성회 총회로 범위를 확정했다(COS-CHURCH-022). [총회소개](https://www.agk.or.kr/bbs/content.php?co_id=sub101)는 여의도순복음교회를 중심으로 하는 교단으로 소개한다. [증명서발급안내](https://www.agk.or.kr/bbs/content.php?co_id=sub407)에는 소속증명서·재직증명서 및 대표자증명서 안내가 확인된다. 2026-10-24 열람 근거이며 교회별 증명 진위·현재 소속·대표 권한 확인 완료를 뜻하지 않는다. 실제 요구 서식과 발급 권한·유효성은 개별 심사에서 확인한다. 이전에 조사한 kihasung.org·khs1953.com은 유사 명칭 비교 자료이며 이번 사용자 지정에 자동 포함하지 않는다. 교단의 다른 시점 분립/통합·기관 관계도 이름만으로 자동 승계하지 않는다.
