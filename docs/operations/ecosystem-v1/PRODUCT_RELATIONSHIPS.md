# 제품 운영 관계와 도입 유형 — v1.5 일관성 보완

2026-10-24. 사용자의 추가 방향 반영. 실행 구현·제품 간 계약 승인 전인 운영 설계다.

## 도입 유형

| 유형 | 교회가 선택하는 범위 | 주요 사용자 흐름 |
|---|---|---|
| A. 교회 기본 운영 | ChurchOS 화이트라벨·교인·공지·일정·공동체·출석·봉사·후속 업무 | 교회 앱→교회 생활. Academy 미선택으로 기본 기능 제한 없음 |
| B. 앱 내 기도·말씀 | A의 기본형 말씀/기도 요구, 제공자 준비와 권리 범위에 맞춰 구현 | 교회 앱 안에서 JLPrayer 기도수첩·공동기도, JLBible 성경·찬송 사용. 통독/전문 기능은 제품 이동 |
| C. Academy 참여 | A + 별도 선택한 Academy + 과정에 연결된 너랑나랑·생명일기 | 교회 앱→Academy 과정→너랑나랑 활동→생명일기 실천·나눔 |
| D. 개인 독립 사용 | 원하는 전문 제품 직접 사용 | 교회·Academy 도입 없이 핵심 개인 기능 사용. 교육 자료·이용권 조건은 제품별 안내 |

CHGO는 위 도입 유형과 별도로 모든 제품의 개념·관계·허용된 해석을 지원하는 독립 엔진이다. 모든 교회에 CHGO 별도 메뉴·개인 평가 기능을 판매하거나 노출한다는 뜻이 아니다. 엔진의 제품별 사용 범위는 계약으로 정한다.

## v1.2 말씀 기능 추가

교회 앱 내 성경·찬송 뷰어를 제공하고 통독은 JLBible에서 사용한다. 설교 링크·원고·음성·요약·말씀 나눔지는 Academy 선택과 무관한 ChurchOS 교회 콘텐츠다. CHGO가 개념·근거를 연결하고 별도 생성 어댑터가 초안을 지원하며 목회자가 검토·게시한다. 상세 계약과 미구현 상태는 [말씀 운영 설계](WORD_AND_SERMONS.md)를 따른다.

## ChurchOS 기능 범위

| 구분 | 포함 |
|---|---|
| 화이트라벨 | 교회명·로고·색·앱 표시 설정, 공용 앱과 개별 교회 앱 배포 방식 구분 |
| 기본 운영 | 소속·역할·교인·공지·일정·공동체·출석·봉사·후속 업무·감사, API 기반 기도·말씀 화면 |
| 연결 | 교회별 활성 제품, 개인 연결, 안전한 앱 이동·복귀, 연결 오류 안내 |
| 운영 화면 | 교회별 역할 범위의 관리자·목회자 화면, 운영 통계 |

회계·헌금·시설 예약·방송·문서 결재 등은 교회 기본 기능의 전체 목록으로 임의 포함하지 않는다. 필요도·중복·결제/운영 책임을 조사해 후속 백로그로 판단한다. 기본 기능은 위 MVP 범위부터 구현한다.

## Academy 참여 교회의 책임

| 업무 | 책임 제품 | 연결 대상 |
|---|---|---|
| 교회의 Academy 도입 선택 | ChurchOS 연결 설정 + Academy 교회 등록 | 교회 식별 참조, 중복 등록 방지 |
| 과정·개설반·강사·차시·수강 | Academy | ChurchOS 행사·소속 참조 |
| 현장 모임·시간·장소·출석 | ChurchOS | Academy가 필요 시 허용 운영 사실 수신 |
| 너랑나랑 활동 안내 | Academy | 너랑나랑이 세션·참여자·문답·서명을 관리 |
| 생명일기 실천 계획 | Academy | 생명일기가 작성·회차·개인 공유·코칭 관리 |
| 나눔 모임 운영 | ChurchOS 일정·출석, 생명일기 공유·코칭 | 서로 원문·작성 상태 복제 없음 |
| 수료 | Academy | ChurchOS 출석과 개인 기록을 자동 등치하지 않음 |
| 수료 후 실천 지속 | 생명일기, 교회 모임은 ChurchOS | 수강 종료·코치 권한·공유 기간 별도 처리 |

## 전 제품과 CHGO의 연결

아래는 연결 설계 대상이다. 원문 수신 권한이나 실제 API 구현 완료를 뜻하지 않는다.

| 요청 제품 | CHGO와 연결할 영역 | 원래 제품에 남는 정본 |
|---|---|---|
| ChurchOS | 공동체 개념/허용 집계와 교회 설교의 개념·근거·초안 지원 | 교회·소속·출석·봉사·업무·설교·승인 나눔지 |
| 너랑나랑 | 관계 활동과 성장 개념 대응·허용 규칙 참조 | 답변·세션·은혜 기록·서명 |
| 생명일기 | 7문항/성장 개념 대응·허용된 코칭/해석 기능 계약 검토 | 문항·개인 기록·회차·공유 |
| JLPrayer | 기도 활동 개념 대응·허용 근거와 해석 | 기도제목·기도방·참여·응답 |
| JLBible | 본문 참조와 성장 개념의 검토된 연결 | 성경 본문·라이선스·통독·성경 온톨로지 |
| Academy | 교육 목표·차시·성장 개념 연결·허용된 해석 | 과정·교재·수강·평가·수료 |

개념 매핑은 데이터 이동 없이도 가능하다. 개인 근거 교환은 별도 계약이 없는 한 비활성이다. CHGO 엔진이 성경 본문·교육과정·개인 기록을 대신 소유하지 않는다. 엔진 출력의 대상도 제품별로 제한하며 ChurchOS가 모든 결과를 받지 않는다.

## 다음 구현 작업 순서

1. 교회 기본 기능 목록과 화이트라벨 배포 방식을 MVP 단위로 확정한다.
2. Academy 미참여/참여 교회의 홈·연결 메뉴를 나눈다. 모든 교회에 교육 과제를 노출하지 않는다.
3. Academy 교회→개설반→차시→너랑나랑·생명일기 활동 참조 계약을 정의한다.
4. 생명일기 제품에서 코칭·공유·교육 종료 후 지속 흐름의 현재 구현을 대조한다.
5. 각 제품과 CHGO의 개념 ID·입출력·권한·버전·장애 계약을 정의한다.
6. ChurchOS 기본 파일럿과 Academy 참여 교회 파일럿을 별도 검증한다.

가격, 강좌별 필수 활동, 개인 근거 제공 범위, CHGO 출력 상세는 미확정이다. 관련 제품 원본과 대조한 후 결정한다.
