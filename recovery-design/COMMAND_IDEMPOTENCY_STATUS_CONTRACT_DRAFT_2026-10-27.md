## 합의 범위

동일 요청 식별자는 같은 업무·내용에만 쓰고, 다른 내용은 거절하며, 응답이 끊기면 기존 결과 확인을 우선한다. 이전 문서의 전체 경로·필드·보유·상태표가 승인된 것은 아니다. 질문·답변 원문은 아래 확정 근거 절에, r25 본문 전체는 [보관본](archive/COMMAND_IDEMPOTENCY_STATUS_CONTRACT_DRAFT_2026-10-27_r25.md)에 있다.

## 기존 구현을 출발점으로 사용

[실제 기준선](IDEMPOTENCY_BASELINE_ALIGNMENT.md)을 따른다. v2.6은 자원별 쓰기 API의 Idempotency-Key 헤더, 검증된 actor_ref+tenant+route+key, 영수증 및 동기 트랜잭션을 이미 구현한다. 본문의 request_id와 범용 POST commands를 별도 중복 방지 체계로 구현하지 않는다. 헤더 키 형식(16~128 인쇄 가능 ASCII), 기존 If-Match·428/412·입력 422·만료 409 계약은 canonical 그대로다.

후속 조회 기능에 필요한 사용자 확인 번호는 기존 멱등 처리의 영수증과 명시적으로 연결하는 후보다. 그 번호와 멱등 키를 같은 값으로 쓸지 별도 불투명 참조를 둘지, 기존 성공 영수증과 신규 접수 기록을 어떻게 연결할지는 OPEN이다. 기존 키는 무작위성을 보장하지 않으므로 키 값을 그대로 공개 확인 번호로 안전하다고 가정하지 않는다. 경로/행위가 다른 키를 전역 동일 요청으로 합치는 것도 승인하지 않는다.

## 후속 조회 확장 후보

| 항목 | 설계 방향 | 상태 |
|---|---|---|
| 쓰기 | 기존 자원별 경로와 Idempotency-Key 사용을 기준으로 확장 | 기존 구현 확인 / 새 적용 범위 대조 필요 |
| 최소 상태 직접 조회 | 별도 읽기 전용 경로, 현재 계정/선택 교회/소속과 본인 영수증 참조 검증 | 경로·식별 매핑 DRAFT |
| 본인 발견 | 현재 선택 교회의 본인 최소 상태만 | 범위 REC-029 AGREED / 경로·페이지 DRAFT |
| 조회 시각 | 미확정 최초 실제 접수+168h, 최종 실제 확정+168h | REC-030 AGREED / 접수·확정 증거 구현 필요 |
| 공개 항목 | 다섯 항목 제한 | REC-031 AGREED / JSON 이름 DRAFT |

기존 성공 영수증에는 영속 PROCESSING/REVIEW_REQUIRED나 실패 접수 결과가 없다. PROCESSING·COMMITTED·REJECTED·REVIEW_REQUIRED는 후속 후보 상태이며 기존 서버 응답이 아니다. 실패 응답 모두를 영수증에 저장한다고 가정하지 않는다. RESULT_UNKNOWN은 앱이 결과를 모르는 상태이지 서버 실패 확정이 아니다. 최종 확정 시각은 실제 증거가 필요하며 기존 created_at/now()를 실제 COMMIT 시각으로 자동 간주하지 않는다.

## 응답과 보안

새 조회 응답의 성공/대기 200/202 및 비공개 404 등은 후보이며 구현 전 상세 계약을 정한다. 기존 자원 API 상태 코드를 덮어쓰지 않는다. 타인/타교회/미존재/기간 만료를 구분하는 응답을 제공하지 않는다. 404를 만료 증거나 미실행 증거로 사용하지 않는다. API 토큰·현재 계정·유효 소속을 먼저 검증하고 일반 업무 역할만 종료된 본인의 최소 조회와 기존 쓰기 재생 권한을 구분한다. 읽기 결과 확인을 위해 쓰기 재전송을 자동 수행하지 않는다.

## 재시도·원자성·삭제

기존 잠금/트랜잭션/영수증을 재사용하는 방향으로 상세 설계한다. 현재 기존 행 만료 후 409를 반환하지만, 기록을 삭제하면 prior 없음 분기로 갈 수 있으므로 24시간 뒤 지워도 된다고 해석하지 않는다. 168시간 조회를 위해 영수증 재생을 단순 연장할지 별도 최소 조회 투영을 유지할지는 OPEN이다. 후자가 기존 쓰기 재생 의미와 최소 공개를 분리하기 좋으므로 우선 검토한다. 실제 수명·상한·삭제 후 재사용 차단·수동 확인·복원 계약 전 운영 적용하지 않는다.

- 같은 키 같은 경로의 동시 제출은 업무 변경 한 번. 다른 입력 거절.

- 응답 유실·권한 해제·교회 전환·실제 뒤늦은 최종 확정·기록 삭제/복원에도 자동 재실행 금지.
- 현재 코드가 모든 후속 조건을 충족한다고 주장하지 않는다.
