# 최소 증빙의 수명 전환·종결·보유 기산 계약 초안

2026-10-30 / r113 / TECHNICAL_LIFECYCLE_DRAFT / PARTIAL_RECOVERY / 실행 NOT_RUN

## 범위와 권위

[r112 EV01~05](LEADER_INTRO_MINIMUM_EVIDENCE_REFERENCE_DRAFT.md), [r109 보유대조](LEADER_INTRO_SUPPORT_RECORD_RETENTION_COMPARISON.md), [REC-082 목적분리](RECOVERY_DECISIONS.md#rec-082-개인-소개자료교회-운영-이력최소-증빙의-목적-분리)를 연결한다. 실제 사건별 기산 근거와 수명 전환을 설계하되 새 보유기간·권한·예외승인·실제종결을 확정하지 않는다. 소개철회/명칭증빙 전체에 기존 종료이력1년·백업30일을 적용하지 않는다.

핵심 보완은 ‘사용중→목적종료→정리대기→삭제·백업종결’을 단일 상태열로 구현하지 않는 것이다. 같은 철회증빙도 동의는 철회됨, 제한된 증빙목적은 유효함, 본문은 삭제됨, 특정백업은 만료대기일 수 있다. 각 상태를 목적/사본/세대별로 구분한다.

## 독립된 상태 축 — 기술 후보

| 축 | 상태의 예 | 의미/불변조건 |
|---|---|---|
| L1 업무 효력 | 동의유효/철회확정/직함종료로현재공개불가 | 어떤 현재공개가 허용되는가; 보유상태로 과거효력 복구 안 함 |
| L2 목적/보유 근거 | 목적사용중/목적종료판정대기/목적종료확인/유효한한정예외 | 필요한최소증빙을 왜남기는가; 잠재분쟁만으로 사용중 무기한고정 금지 |
| L3 정리 실행 | 아직삭제대상아님/정리대상확정/처리중/부분실패/운영본삭제확인 | 실제 어느자료를 지웠는가; 작업접수/큐비움은 삭제확인이 아님 |
| L4 사본/보호 종결 | 사본조사중/백업잔존/최신상태재적용필요/사본별만료확인/보호목적종료확인 | 원문백업·실행/복원보호참조 수명이 각각다름; 전체완료단정 금지 |

용어는 API enum/새테이블명이 아니다. L2의 목적종료와 보유마감/실제삭제시한은 다를 수 있으며 정책수치가 확정돼야 계산한다. 같은 레코드의 유효목적이 여러개면 목적/필드별필요성·마감·접근을 한정하고 다른목적을 이유로 원문 전체를 계속보관하지 않는다.

## 시각의 의미와 수정 규칙

| 시각 후보 | 기록할 사실 | 초기화/오인 금지 |
|---|---|---|
| 최초접수 | 실제 서버가 처음 유효접수한 요청 사건 | 재시도/담당변경/전달로 새접수시각 생성 안 함 |
| 동의/철회 확정 | 해당세대의 실제 서버업무 확정 | 클릭/네트워크도착/조회시각을 대신 쓰지 않음 |
| 목적종료 확인 | 정의된목적종료 근거·판정주체/사건 | 임의관리자수정·관련없는 조회로 목적연장 금지 |
| 정책상 보유마감 | 확정된목적/근거/기산+적용정책버전 | 미결수치로가짜마감생성·다른업무기간자동이식 금지 |
| 삭제실행 시한 | 대상정책에서 정한 실행마감 | 보유마감과혼동·작업늦게접수해기한연장 금지 |
| 실제 운영본삭제 | 각 대상/사본의 삭제확인 사건 | 삭제요청/일부성공을 모든사본삭제로 표시 안 함 |
| 백업원래만료/실제만료확인 | 적용대상의 원래상한과 실제처리 | 복제/복원/이관으로 원래상한초기화 안 함 |
| 보호목적종료/최종정리 | 남은복원/재실행경로의 종료 근거와 최소참조삭제 | 과거동의/옛권한자동부활·근거없는영구필터 금지 |

보유마감/실행시한/최종정리는 별도다. 마감이 지났는데 삭제가 실패하면 위반/지연 상태를 확인하고 필요한운영조치를 인계한다. 실패했다는 이유로 마감을 새로 시작하지 않는다. 신뢰시각/UTC·교회표시시간대·정정시계산 방식은 구체계약에서 확정하되 날짜문자열만으로 사건순서를 판정하지 않는다.

잘못기록된시각/종결을 정정할 때는 원값/정정근거/효력·기한영향을 분리한다. 원본덮어쓰기·보유연장을 위한 재종결 금지. 실제정정권한·오류사유/검토·동시삭제경합은 OPEN이며 추가확인담당에게 자동부여하지 않는다.

## 예외·복원·새 동의

예외보관은 필요목적/최소필드/승인자격/종료/재승인 조건이 확정돼야 하며 신청/확인중/일반이의가능성만으로 자동연장하지 않는다. 기존 COS-JOIN/SSO 예외승인 규칙을 새소개증빙/지원감사에 곧바로 확대하지 않는다. 구체예외정책/실제책임자는 미결이다.

새동의·재이용·재지정은 새사건/세대로 결속한다. 과거철회/삭제대상이나 이전백업 기산을 새동의로 초기화하지 않는다. 새콘텐츠가 이전삭제대상과안전하게분리됐는지 검증하기전 삭제배치/공개복원을 허용하지 않는다.

복원본에는 각축의 실제현재상태와삭제·회수·실행확정을 재적용한다. 오래된동의가사용중이었거나 증빙보유가남았다는 이유로 공개효력·지원권한을 살리지 않는다. 최신근거를 확인하지못하면 격리/공개보류하고 실제인계한다. 통제밖외부사본 회수완료를 일괄보장하지 않는다.

## 남은 정책값과 완료 판정
