# 미확정 요청 내부 확인·상향 전달·종결 기준 초안

2026-10-31 / r138 / INTERNAL_RESOLUTION_DRAFT / PARTIAL_RECOVERY / 실제 실행 NOT_RUN

## 범위

[REC-087 적용](LEADER_INTRO_PENDING_GAP_AGREED_HANDOFF.md), [r126 커밋/결과 한계](LEADER_INTRO_SYNC_ACCEPTANCE_MODEL_COMPARISON.md), [r127 결과 근거](LEADER_INTRO_MINIMUM_RESULT_FIELDS_TIME_CARD.md), [기존 REC 원문](RECOVERY_DECISIONS.md)을 따른다. 일반 화면에서 빠진 미확정 요청이 내부에서 무기한 방치되지 않도록 책임/근거/종결 조건을 제안한다. 실제 담당·기한 숫자·새 조사/정정/DB권한은 확정하지 않는다.

REC-079~081의 담당 선임/건별 배정/이해충돌 원칙은 추가 확인 운영의 기준으로 유지하되, 그 담당에게 기술적 커밋 조사/DB접근권을 자동 부여하지 않는다. 기술 확인 역할과 사용자 안내 역할은 목적별로 다르다. 이번에 운영 인력이나 조사 기능을 실제 지정/구축하지 않았다.

## 두 결과를 분리

| 축 | 질문 | 가능한 근거/의미 후보 |
|---|---|---|
| 업무 결과 | 이 특정 요청이 해당 동의 세대의 변경을 확정했는가 | 검증된 철회 확정·변경 없는 최종 거절·아직 불명 |
| 확인 업무 | 정해진 범위의 근거 확인을 마쳤는가 | 확인 진행·전문 역할 인계·근거 확보 종결·확인 불가 종결 후보 |

확인 업무 종결을 업무 성공/거절로 저장하지 않는다. 반대로 업무가 불명이라고 동일 조사를 영구 반복/보유하지 않는다. 확인 불가 종결은 ‘이 요청의 결과를 입증할 근거를 확보하지 못했다’는 한계를 뜻한다. 실제 미실행·철회 효력 부활·새 실행 허용·전체 사본 삭제 완료가 아니다. 정식 상태명/저장 스키마는 미선정이다.

## 책임 역할 후보

| 논리 역할 | 허용 목적 | 자동으로 생기지 않는 권한 |
|---|---|---|
| 배정/상향 전달 책임 | 현재 적격자와 필요한 범위·유효기간 확인 | 원문/사진·전체 업무 검색·자기배정 예외 |
| 접수/안내 담당 | 해당 건의 최소 참조와 안내/인계 | 대신 철회·결과 정정·DB운영권 |
| 기술 근거 확인 담당 | 명시적으로 허용된 최소 운영 메타/결과 근거 조사 | 포괄 DB덤프·개인 원문·타제품 기록 열람/재실행 |
| 종결/이의 검토 역할 | 확인 범위/근거 한계와 종료 기준 검토 | 실제 업무 결과를 임의 생성·기록 소급 변경 |

이는 네 사람을 반드시 따로 고용하거나 기존 교회 관리자에게 부여하라는 뜻이 아니다. 실제 자격/겸임/독립 검토·건별 접근을 정해야 한다. 기존 자기선임/자기배정/충돌 자기승인 금지를 유지하고, 담당 상실 후 접근 차단·별도 인계를 요구한다. 책임자 공백을 무권한 조사나 대리 철회로 메우지 않는다.

| 단계 | 입력/판정 | 산출·실패 처리 |
|---|---|---|

| IR02 배정 | 현재 적격/목적/범위·충돌·대행 검증 | 한정된 확인 과제와 원래 접수/기산 유지 |
| IR03 근거 대조 | 허용된 내구 접수/최종 근거·세대·버전·커밋 불명 | 사실/추론/누락을 구분, 현재 자원 상태만으로 과거 결과 소급 구성 금지 |
| IR04 상향 전달 | 범위 밖 기술 근거·권한 부족·불일치·기한 임박 | 적격 역할에 최소 참조 인계, 현재 접근 범위를 임의 확대하지 않음 |
| IR05 종결 판정 | 아래 종결 유형과 증거 대조 | 업무 결과와 확인 종결을 각각 기록하는 후보 |
| IR06 안내/정리 | 현재 허용 본인 안내·수명/예외/보호 판정 | 일반 조회 마감 우회 없이 안내, 목적 종료 기록/사본 유한 정리 |

IR 흐름은 사람이 원래 철회 실행을 대신하는 절차가 아니다. 내부 확인 성공이 원래 업무의 실행 재개 승인이 되지 않는다. 실행 중 작업을 취소/재실행/보정할 권한은 별도 변경 계약이다.

## 종결 유형과 최소 근거

| 유형 후보 | 필요한 것 | 주의 |
|---|---|---|
| 검증된 최종 결과 발견 | 정확한 요청/동의 세대 결속·실제 확정 근거·시각 의미 | 늦게 발견됐어도 발견 시각으로 최종 창을 새로 시작하지 않음 |
| 원래 처리/확정이 계속 진행 | 실제 처리 주체·현재 상태·명시적인 유한 다음 확인/종결 조건 | 이 분기는 종결이 아님, 무기한 연장 금지 |
| 중복 확인 건 | 동일 요청 관계·선행 건·결과/미결 참조 | 확인 건 중복 종료이지 원래 W 취소/실패가 아님 |
| 확인 불가 종결 | 정해진 허용 근거 범위·수행한 확인/누락·추가 조사 불가 이유·승인된 종료 기준 | 빈 로그/404만으로 불명 업무를 거절 처리하지 않음 |
| 권한/범위 부적합 | 현재 자격/관계 검증과 최소 사실 | 타인 요청 존재를 안내하거나 포괄 탐색권 부여 금지 |

확인 불가 종결에는 적격 검토/안내·기록 수명·옛 실행 경로의 상태/보호 조건이 필요하다. 실제 작업이 나중에 확정될 수 있으면 작업 수명/종결과 확인 건의 관계를 명세해야 한다. 재검토 가능 사유·근거·원래 기산 보존은 별도이며 재개할 때마다 시계를 초기화하지 않는다. 실제 보정/취소를 이번 초안으로 승인하지 않는다.

## 유한 확인/종결 계약에 반드시 채울 항목

최초 유효 확인 접수 사건·첫 확인/정기 안내·상향 전달·최대 확인/종결 상한·주말/시간대 계산·대행/부재·연장 승인/횟수·예외 종료·자료 정리/백업을 정해야 한다. 숫자는 모두 OPEN이다. 과거 특정 계정탈퇴 전달 실패에 적용된24시간 규칙을 일반 내부 조사 기한으로 자동 이식하지 않는다. Q168시간/WR 미정 조회 창·영수증24시간도 조사 상한이 아니다.

담당 교체·상향 전달·새 접수번호·재로그인·같은 근거 재제출로 원래 확인 기산을 다시 시작하지 않는다. 유효한 제한 예외가 필요하면 목적/대상/승인·유한 종료를 별도 기록하되 일반 본인 조회창이나 모든 자료 보유를 자동 연장하지 않는다. 실제 담당과 기한이 비어 있으면 운영 준비 완료가 아니다.

## 안내·기록의 최소 경계

본인 안내 후보는 ‘이 요청의 최종 결과를 추가 확인하고 있습니다’ 또는 ‘허용된 확인 범위에서 이 요청의 최종 결과를 확인하지 못했습니다’다. 이것을 일반 만료 목록에 숨긴 행의 상태를 계속 공개하는 수단으로 사용하지 않는다. 별도 지원 안내의 현재 자격·필드·유한 기간을 정해야 하며 REC-087 일반 조회 종료를 우회하지 않는다.

기록은 건/요청 참조·현재 담당/범위·확인한 근거의 최소 참조와 버전·수행/인계·한계·종결 판단/안내·정리 근거 후보다. 소개 원문/사진·토큰·원본 입력·교인 명단·타제품 개인 기록을 조사 로그에 복사하지 않는다. 최소 기록도 개인 관계와 연결될 수 있으므로 접근/보유/삭제/백업을 정한다. 운영 조사 목적을 이유로 영구 보유하지 않는다.

실제 최종이 뒤늦게 발견됐는데 원래 최종 창이 이미 끝난 경우, 발견 시각으로 기간을 바꾸지 않는다. 안내/정정·다른 제한 경로의 필요는 별도 정책으로 검토하며 존재하지 않는 창을 만들어 공개하지 않는다.

## 검증 인계와 다음 결정

합성 조건은 담당 회수/공백·상향 전달 중 시계 유지·COMMIT 불명·현재 상태만 잔존·뒤늦은 최종 발견·진행 중 작업과 확인 종결 충돌·권한 없는 근거·부분 사본 정리·새 동의/계정 전환이다. 정상 대조와 금지 결과 미발생을 확인해야 한다. 기존 CA144/159~162의 세부 인계이며 새 CA나 실행 성공 수를 추가하지 않는다. 모두 NOT_RUN이다.

다음 좁은 결정은 **업무 결과가 불명인 경우, 실제 업무 성공/거절과 별개로 확인 불가라는 한계를 명시한 확인 업무 종결을 둘지**다. 적격 검토·유한 기준·실행/보호 관계가 없는 채로 임의 종결하지 않는 조건을 함께 검토한다. 이번 ‘진행해줘’는 이 원칙·권한/상한의 합의가 아니다.
