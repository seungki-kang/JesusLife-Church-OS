## 조건 유지

MC01~07의 설계/운영 근거와 MC08 구현 후 검증은 미완료다. 현재 정본의 트랜잭션/키/행 버전 구조와 대조하면서 보완해야 한다. 별도 접수 전용 트랜잭션이나 워커를 넣는다면 M2로 경계가 바뀌는지 다시 검토한다. M1이므로 미확정/불명 결과가 없다고 주장하지 않는다.

실제 DB 계보/배포 설정은 미확인이다. 기존 정본 마이그레이션을 덮어쓰지 않는다. 기존 일반 관리자 쓰기 권한이 소속 종료 후 본인 철회권/최소 결과 조회를 보장하지 않는다. 타제품 권한이나 원문 공유를 추가하지 않는다.

## 통합 결정표 후속 상태

DC07의 처리 모델 방향은 REC092로 합의했으나 실제 저장/원자 경계/키 호환은 OPEN이다. DC03 공개 상한은 REC090, 내구 근거 판정은 REC091이 우선한다. DC01/02 실제 담당·권한, DC04/05 시간, DC06 자료 수명, DC08 실행/복원 보호, DC09 안내, DC10 실제 검증은 해소되지 않았다.

## 다음 설계
