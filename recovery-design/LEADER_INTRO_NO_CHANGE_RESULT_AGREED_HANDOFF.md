## 확정 범위

실제 철회 명령으로 제출된 건에 한해, 본인·해당 요청·같은 동의 세대와 이미 철회 상태를 검증한 이번 판정의 최소 내구 무변경 결과를 남기는 N1 방향을 확정했다. 과거 철회 실행 증명을 생성하는 기능이 아니다. 일반 조회마다 새 결과를 생성하지 않는다.

| 행위 | 결과 기록의 의미 | 유지 조건 |
|---|---|---|
| 유효한 명령에서 이미 철회됨 판정 | 이번 요청의 검증된 무변경 판정 | 같은 세대/현재 본인·입력 결속 |
| 같은 요청 결과 재조회 | 기존 결과를 읽음 | 현재 권한·유효 기간·원래 시각 유지 |
| 일반 상태 조회 | 현재 허용 상태를 읽음 | 새 명령 결과 생성 금지 |
| 다른 요청이 이미 철회를 실행 | 두 요청의 실행/무변경 판정 구분 | 과거 실행 성공 소급 금지 |
| 새 동의 세대 공개 | 새 세대를 변경하지 않음 | 이전 세대와 자동 재결속 금지 |

## 상세 설계의 미완료

저장/감사·정식 상태/코드·시각·조회 기산/기간·반복 새 키 제한·기록 정리/복원 보호는 후속 계약이다. 최소 내구 결과가 있다고 말할 수 있으려면 상태 판정과 결과/감사가 일관되게 확정되는 실제 경계가 필요하다. 이번 합의가 그 조건을 충족했다는 뜻은 아니다.

COMMIT 결과 불명이나 응답 유실은 해당 요청 근거를 확인한다. 근거 만료/소실을 미실행으로 판정하거나 새로운 키로 자동 실행하지 않는다. 결과 재조회가 새 기록 생성이나 기산 초기화로 이어지지 않게 해야 한다. 개인정보 최소화·REC090 공개 상한·기존 유한 확인/재검토를 유지한다.

## 다음 설계

실제 효력 변경 결과와 이미 철회됨의 무변경 결과를 같은 요청 식별/멱등 계약 안에서 구별하는 결과표를 만든다. 인증 실패·입력 충돌·업무 거절·확정 불명도 별도 축으로 대조해 어떤 사건에만 내구 결과를 기록할지 정리한다. 구체 상태명/코드와 거절 기록의 확정 경계는 미결로 남기며 원칙 합의를 반복해서 묻지 않는다.
