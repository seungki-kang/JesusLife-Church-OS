# 본인 철회 결과 공개 상한 — 합의 인계

근거: [REC-090](RECOVERY_DECISIONS.md#rec-090-본인-철회-결과-공개-정보의-다섯-종류-상한). [통합 결정표](LEADER_INTRO_PUBLIC_RESULT_LIMIT_AGREED_HANDOFF.md) DC03의 공개 정보 상한 원칙만 합의했다. 실제 응답 계약·기간·기술은 미결이다.

| 공개 가능한 종류 | 표시 근거 | 미검증 시 경계 |
|---|---|---|
| 요청 번호 | 현재 본인과 특정 요청의 서버 결속 | 번호 소지만으로 존재/내용 공개 금지 |
| 처리 상태 | 해당 요청의 내구 근거 | 현재 소개 상태로 과거 결과 추정 금지 |
| 접수 시각 | 검증된 서버 수용 사건 | 기기 전송/자원 생성 시각으로 대체 금지 |
| 최종 결과 시각 | 실제 최종 확정 사건 | 확인 업무 종결/발견 시각으로 대체 금지 |
| 조회 종료 시각 | 확정된 상태별 기간/기산 계산 | 기간 숫자가 미결인 채 임의 산출 금지 |

다섯 종류는 상한이며 항상 다섯 값을 제공하라는 뜻이 아니다. 시각 누락/불명 표현·생략/null 여부·정식 상태명·필드명은 후속 계약이다. 권한·요청 관계·조회 유효성을 확인할 수 없을 때 일부 값만 노출하는 방식으로 우회하지 않는다. 유효한 결과 근거가 있고 시각만 불명인 경우와 권한 판정 자체가 불명인 경우를 구별해야 하며, 실제 응답 방식은 아직 선정하지 않았다.

내부 오류 추적·프로토콜 메타가 필요하더라도 숨은 업무 정보 추가 공개 수단이 되지 않도록 별도 계약을 점검한다. 이 합의는 내부 저장 기록을 다섯 칼럼으로 제한하거나 모든 API의 메타 구조를 확정한 것이 아니다.
