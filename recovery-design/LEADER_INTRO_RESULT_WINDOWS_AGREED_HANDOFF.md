# 미확정·최종 조회 기간 분리 — 합의 적용 인계

2026-10-31 / r132 / AGREED_SCOPED_DESIGN / PARTIAL_RECOVERY / 실행 NOT_RUN

[REC-085](RECOVERY_DECISIONS.md#rec-085-본인-철회-결과의-미확정최종-조회-기간-분리)에 따라 [r131 결정표](LEADER_INTRO_RESULT_LIFETIME_DECISION_PACKET.md)의 상태별 유한 조회 기회 방향을 반영했다. r131 질문/OPEN은 당시 기록으로 보존하고 이 후속 상태를 함께 읽는다.

| 구분 | 이번 확정 | 미결 유지 |
|---|---|---|
| 미확정 확인 | 최종 결과 확인 창과 구분 | 실제 접수 사건·기산·길이·내부 종결 |

| 모델/알림 | 동기/선접수 방식 선정 없음 | M1/M2·실제 API/기록·알림/재발견 경로 |

이번은 ‘유한 기간을 두 부분으로 나누는 방향’만의 합의다. 이전 일반 Q의168시간을 적용하거나 WR 기간을 24시간/7일/90일로 확정하지 않았다. 미확정 창 종료 뒤 실제 최종 결과가 나왔을 때 그 결과를 본인이 찾을 수 있어야 하지만, 이를 위해 전체 이력 목록이나 자동 푸시를 임의로 추가하지 않는다.

조회 창을 약속하려면 해당 창 동안 실제 이용 가능한 최소 결과 기록·현재 자격·요청 결속이 있어야 한다. 기존24시간 성공 영수증만으로 이를 지원한다고 주장하지 않는다. 조회 목적 종료와 실제 DB/사본 삭제 완료도 분리한다. 현재 철회 효력·옛 요청/복원 차단은 각 목적의 유한 계약으로 계속 검토한다.

## 미결 추적의 변화

r131 DP01의 별도 최종 확인 기회 방향은 AGREED_SCOPED다. DP02 미확정의 상세 정책·DP03 기간 숫자·DP04 최소보유·DP05 늦은최종 경로·DP06 보호/복원·DP07 제한/종료는 OPEN 유지한다. r128 공개상한 질문은 여전히 별도 OPEN이다. 미정 항목이 모두 해소된 것처럼 게이트를 닫지 않는다.
