# 로그인→교회 개설→교인 승인→역할 지정 앱 계약

2026-10-28 / 기존 COS 합의 연결 / 화면·상태·API 기술 DRAFT / PARTIAL_RECOVERY / 구현·실행 NOT_RUN

## 읽는 기준

[기존 COS 결정](../docs/decisions/DESIGN_DECISIONS.md), [공통 인증·소속 계약](../docs/operations/ecosystem-v1/ACCOUNT_MEMBERSHIP_SERVICE_SCOPE_CONTRACT.md), [교회 개설 심사](../docs/operations/ecosystem-v1/CHURCH_ESTABLISHMENT_REVIEW.md), [실제 제공자 조사](../docs/operations/ecosystem-v1/AUTH_PROVIDER_AND_PRODUCT_INVENTORY.md)를 근거로 한다. 이 문서는 이미 합의한 정책을 다시 승인받거나 새 기간·역할·입력 항목을 추가하는 결정이 아니다.

여섯 제품의 공통 계정과 서비스 시작/교회 소속/역할/개인 공유는 독립 상태다. CHGO는 사용자 SSO 제품으로 추가하지 않는다. ChurchOS는 같은 앱에서 교인·목회자·관리자 업무를 처리하며 관리자 웹을 필수 경로로 두지 않는다. 지저스라이프 원은 스플래시·로그인·메뉴에 노출하지 않는다.

## 독립 상태 축

| 축 | 판단할 것 | 자동으로 따라오지 않는 것 |
|---|---|---|
| 공통 계정·세션 | 현재 본인 인증·정지/종료·토큰 대상 | ChurchOS 서비스 시작·교회 승인·역할 |
| ChurchOS 이용 | 본인의 서비스 이용 상태·필요 절차 | 탈퇴한 서비스를 SSO 링크로 자동 재활성화 |
| 교회 개설 심사 | 실재성·자격·대표/위임·신학 이용 기준 | 최초 관리자 수락 전 권한 활성화 |
| 교회 소속 | 대기/유효/정지/탈퇴·재가입 제한 | 추가 관리자·심사 담당·제품 개인 권한 |
| 추가 역할 | 현재 지정·수락 필요 여부·범위·기간 | 목회자 직함만으로 업무 권한 |
| 연락 사용·개인 공유 | 제품·교회·목적별 본인 선택 | 가입 승인만으로 운영 연락처 복사·기도/일기 열람 |

상태 이름은 논리적 설명이며 DB enum 선정이 아니다. 기존 v2.6 membership의 PENDING/ACTIVE/INACTIVE를 이 전체 흐름으로 간주하지 않는다. 일반 가입 심사·최초 관리자 활성화는 별도 업무다.

## 진입과 정상 흐름

- 기존 교인: 공통 로그인→현재 ChurchOS 이용 확인→교회 선택→현재 유효 소속/역할 확인→교회 홈.
- 새 교인: 로그인/서비스 시작→공개 교회 확인→이름 필수·연락처 선택→수동 승인 대기→일반 교인 활성. 초대 링크도 승인 생략 없음.
- 교회 개설 신청자: 로그인/서비스 시작→임시 설정→두 기본 서류/유형별 대체 자료→사람 심사→최초 관리자 지정→대상 본인 수락→최초 소속·관리자·이력 일관 반영→초대/관리 업무.
- 추가 관리자: 해당 교회 유효 소속 교인→현재 유효 관리자 지정→대상 본인 수락→활성. 미수락 지정은 마지막 관리자 보호의 후임으로 계산하지 않음.

최초 관리자 활성화는 COS-JOIN-027의 개설 전용 절차다. 기존 관리자가 없는 최초 교회에 일반 교인 가입 승인을 선행 요구하는 순환을 만들지 않는다. 기존 교회 데이터 병합/관리자 교체로 신규 개설을 우회하지 않는다.

## 가입 심사의 원자성과 입력/사유

COS-JOIN-004: 심사 결과·소속 변경·이력은 일관된 확정 단위로 반영한다. 동시 승인/거절은 먼저 유효 확정 하나만 인정하고, 통신 재시도는 소속을 중복 생성하지 않는다. COS-JOIN-006: 같은 계정/교회 대기 요청 하나, 초대·기기가 달라도 새 대기 요청을 만들지 않는다.

COS-JOIN-035: 이름/선택 연락처의 본인 대기 수정은 요청 버전을 갱신하며 구버전 심사를 차단한다. 종료된 심사는 이 수정으로 덮어쓰지 않는다. 기존 계정 프로필 변경도 가입 요청 수정과 별개다.

COS-JOIN-033/034: 거절 사유는 ‘교인 확인 불가’ 또는 ‘대상 교회 착오’ 중 하나. 기타·자유 메모·개인 신앙/성숙도 평가를 추가하지 않는다. 본인에게 표준 안내와 재신청 경로, 다른 심사자에게는 COS-JOIN-025의 종료 최소 결과만 제공한다.

정지·미해제 재가입 제한·중복·기술 오류를 거절 사유로 덮어쓰지 않는다. 거절/취소 뒤 새 재신청은 가능하나 기존 결과·이력을 되살리거나 자동 승인하지 않는다. 이미 유효 소속이면 새 요청/소속 대신 해당 홈을 안내한다. 소속 레코드 재사용/신규 생성의 기술 선택은 OPEN이다.

| 종류 | 부여·활성 근거 | 수락/기간 | 해제·회복 |
|---|---|---|---|

| 일반 업무 담당 | 최소 업무 범위의 관리자 지정·본인 수락 | REC-001~024 범위별 합의 | 범위 축소/해제·일반 기간/연장 규칙 적용 |

최초/추가 관리자 수락 기한 168h는 활성 관리자 임기가 168h라는 뜻이 아니다. 일반 업무의 최대 1년·행사 정정 7일을 관리자/가입 승인 특별 권한에 적용하지 않는다. 목회자 직함·교회 비용 지불·Academy 참여는 자동 권한 근거가 아니다.

## 마지막 관리자와 종료의 다른 경로

COS-JOIN-011/015/019: 일반 교회 업무상 마지막 관리자 역할 해제/정지/교회 탈퇴는 다른 유효 관리자 확보를 확인해야 한다. 미수락 후임을 유효 후임으로 계산하지 않는다. 동시에 두 관리자가 서로 해제/탈퇴해 0명이 되지 않도록 서버 경합 명세가 필요하다.

COS-SSO-020: 마지막 관리자라도 공통 계정 탈퇴는 허용하며 접근을 남겨두지 않는다. 후임 미확보는 별도 관리 공백 복구 사안이고 후임을 자동 지정하거나 교회 원본을 삭제하지 않는다. 계정 보안 정지도 마지막 관리자 보호를 이유로 무효화하지 않는다. 가입 결과 정정에서 마지막 관리자 보호의 구체 적용은 기존 OPEN을 유지한다.

## 개인정보·연결·알림

심사 서류는 배정 심사자 화면에서 현재 권한으로만 열람한다. 기본 다운로드·외부 공유·이메일 첨부·오프라인 보관·AI 전달 없음. 자료/사유/연락처를 푸시 미리보기·로그·이벤트에 복제하지 않는다.

COS-JOIN-037~039: 승인 후 교회 운영 연락은 본인 별도 선택이며 철회 시 이후 열람/새 발송을 차단하고 해당 교회 운영 사본을 168h 내 삭제한다. 계정·다른 교회·별도 심사 기록을 포괄 삭제하지 않는다. 연락처 백업/반출·대기/진행 발송은 별도 미결이다.

교회 선택/가입 승인은 JLPrayer의 개인 수첩·생명일기·너랑나랑 원문 접근을 주지 않는다. JLBible 통독·Academy 수강/수료·CHGO 허용 입력도 각 제공자 계약을 따른다.

## API 인계와 미결

[작업별 API/권한 매핑](ONBOARDING_CAPABILITY_MAP.csv)은 기능 계약 후보이며 실재 경로/OpenAPI를 선언하지 않는다. 가입/개설 특별 흐름에 r29 일반 업무 명령의 상태/조회168h/처리영수증을 자동 이식하지 않는다. 공유할 기술은 각 특별 계약의 권한·공개 범위를 먼저 대조한다.

미결: 실제 인증 제공자·로그인 복귀·제품 토큰/식별, 심사/소속/역할 상태 코드, 개설 증빙 필드·심사자/대행 선임·신학/기관 목록 운영 채택, 권한 확인 유효기간·분쟁 재개, 최초 지정 취소/거절 세부, 담당자 수락/임기 상세, 마지막 관리자 경합/정정 적용, 연락처/최소 이력의 남은 수명, 전체 오류/재시도/상태 조회 기술이다.

[교회 개설 자료 수명 보완](CHURCH_EVIDENCE_RETENTION_SUPPLEMENT.md)과 [앱 흐름 수용 시나리오](ONBOARDING_ACCEPTANCE.csv)를 함께 적용한다. 코드·실기기·SSO·업무 실행은 NOT_RUN이다.
