## 기산 사건과 증거 — 후속 상세 계약 초안

다음 항목은 구현 필드 확정이 아닌 인계 후보다.

- 유효 탈퇴 확정: 검증된 종료 건·범위·정책 버전·최초 확정 시각. 전달/재시도 시각과 분리.
- 운영본 삭제 완료: 정본·운영 사본·대상 파생본의 범위와 각 실제 완료 시각. 일부 사본만 삭제해 전체 완료 표시 금지.
- 백업 잔존 종료: 사본별 보관 상한·만료 결과·누락 확인. 백업을 새로 복제해 원래 데이터의 만료를 초기화하지 않음.
- 실제 종결: 통지/실패/예외/백업 등 필요한 후속 처리가 끝났다는 범위별 근거. 실패를 종결로 바꿔 보유 시계를 시작하지 않음.
- 예외: 목적·최소 범위·요청자·별도 승인자·승인 종료·철회/목적 종료·다른 유효 근거. 심사 중이라는 이유로 자동 연장 금지.
- 삭제 확인에는 최소 건 참조·처리 결과만 남기며 삭제된 원문/토큰/연락처를 증거로 복사하지 않음. 그 확인 기록 자체의 기간도 별도 계약 필요.

여러 사본의 삭제가 순차적일 때 하나의 마지막 완료 시각으로 이미 지워진 사본의 백업 시계를 늦추지 않는 추적 방식을 제안한다. 실제 저장 단위·공통 정책 시각·사본 계보 계약은 OPEN이며 새 합의로 간주하지 않는다.

## 복원 전 확인 순서 — 설계 수용 조건

1. 복원 환경의 일반 공개·알림·외부 작업·요청 재실행을 보류한다.
2. 최신 삭제/탈퇴/예외 종료 및 현재 계정·교회 소속·권한과 실행 확정 근거를 재적용한다.
3. 원래 접수/확정/삭제 시각으로 조회·백업 기한을 재계산한다. 복원 시각으로 초기화하지 않는다.
4. 최신 상태 근거를 확인할 수 없는 대상은 공개·실행을 재개하지 않고 한정된 담당자 확인으로 전달한다.
5. 일반 조회·업무 재실행·알림·운영 접근의 재개를 각각 확인한다. 백업에 데이터가 있다는 이유로 개인 복구를 제공하지 않는다.

새 기술 절차의 구체 구현은 초안이다. 기존 합의인 복원 공개 전 삭제·권한 재적용을 구현 완료했다고 표시하지 않는다.

## 우선 보완 순서 — 이번 권장안

1. R01: 조회 차단 후 상태 조회용 데이터의 물리 삭제 대상·시한·백업 범위를 정한다. 뒤늦은 최종 확정 조회와 중복 방지 기록은 별도 유지 조건을 설계한다.
2. R02/R15: 실행 유효 기한과 삭제/복원 후 재실행 차단 근거를 함께 정한다. 보유 숫자부터 임의 결정하지 않는다.
3. R05/R06: 기기 참조와 조사 기록의 상한·종결·담당·정리 실패를 정한다.
4. R07/R13/R14: 이미 정한 보유기간을 바꾸지 않고 삭제 완료 시한·이력 자체 백업·종결 판정·1년 계산 세부를 보완한다.
5. R03/R04/R16: 업무/감사/증빙 종류별 최소 필드·권한·기간을 대조한다. 전문 제품 원문은 해당 정본 계약에서 검토한다.

이번 요청은 대조 작업 승인이다. 위 권장안, 새 기간, 새 삭제 방식에 대한 사용자 동의로 기록하지 않는다. 미결 결정은 필요한 항목부터 한 질문씩 제시한다. 코드·파일럿은 계속 보류한다.

## 이번 검사 범위

원문 근거 경로·결정 ID 존재, 새 문서 상대 링크, ZIP CRC, r24 기존 항목 바이트 보존(현재 색인만 갱신)을 검사했다. 실제 삭제·백업 만료·복원·SSO·DB·앱 실행 검증은 NOT_RUN이다. GitHub 원격 변경 없음.

## 구현 기준선 참고

v2.6에는 Idempotency-Key·경로별 영수증·24시간 성공 응답 재생이 이미 구현돼 있다. 후속 수명·조회 설계와의 관계는 [기준선 대조](IDEMPOTENCY_BASELINE_ALIGNMENT.md)를 단일 기준으로 따른다. 이 문서의 후속 수명 OPEN 표시는 기존 구현 부재를 뜻하지 않는다.

출처 주의: 일반 장애 24시간 수동 이관의 근거 범위는 [결정 색인](RECOVERY_DECISIONS.md)의 REC-017 항목을 단일 기준으로 따른다.

## r30 기존 개설 자료 정책 대조 정정

R16을 [개설 증빙 수명 보완](CHURCH_EVIDENCE_RETENTION_SUPPLEMENT.md)에 맞춰 세분화했다. 기존 CHURCH 합의의 확인이며 새 보유기간 승인이 아니다. 과거 “증빙 보유 OPEN” 요약은 이 범위를 충분히 반영하지 못했다.
