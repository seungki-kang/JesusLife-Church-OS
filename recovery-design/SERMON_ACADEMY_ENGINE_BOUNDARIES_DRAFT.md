# 설교·CHGO와 Academy·실천 연결 상세 경계

근거는 [말씀 운영](../docs/operations/ecosystem-v1/WORD_AND_SERMONS.md), [제품 관계](../docs/operations/ecosystem-v1/PRODUCT_RELATIONSHIPS.md), [연결 계약](PROVIDER_CONNECTION_CONTRACT_DRAFT.md)이다.

## 설교 입력에서 승인 게시까지

1. ChurchOS 편집자가 교회·설교·소스 버전·처리 목적·허용 범위를 확인한다. YouTube 재생 링크만 있으면 내용 추측/다운로드/음성 추출을 하지 않는다. 원고·허용 음성·검토 가능한 자막을 별도 확보한다.
2. 음성 전사는 별도 STT 어댑터가 맡는다. 오인식/인명/본문·개인 간증 구간을 검토하고 불필요한 제3자 정보를 제외한다. 미검토 전사를 목회자의 확정 발언으로 게시하지 않는다.
3. CHGO에는 허용된 특정 소스 버전과 범위만 보내 개념·근거 위치·사용 규칙/정본 버전·불확실성을 받는 계약을 둔다. 원고 전체가 항상 필요한지 검토하고 허용 입력 이상을 자동 확대하지 않는다. 개인 기록 원문을 입력하지 않는다.
4. 자연어 생성 어댑터가 그 근거를 사용해 요약/나눔지 초안을 만든다. CHGO=STT=생성모델로 합치지 않는다. 전사/엔진/모델 제공자·저장지역/보유/학습 사용 조건은 미확인이다.
5. 입력 소스/범위/엔진/생성 설정/출력 버전을 묶어 검토한다. 소스 없는 주장·인용·설교자 발언을 자동 추가하지 않는다. 엔진의 적용 제안은 원 설교 주장과 표시를 구분한다.
6. 현재 유효 편집/승인 권한자가 특정 출력과 공개범위를 확인해 게시한다. 설교 게시와 나눔지 승인은 독립이다. 목회자 직함만으로 모든 권한이 생기지 않는다. AI가 승인자를 대신하지 않는다.

소스 변경/공개 철회/처리 권리 상실 뒤 도착한 결과는 공개하지 않고 현재 권한과 버전을 재검증한다. 취소 요청은 외부 처리 완료/입력 삭제의 증명이 아니다. 파생본의 독립 보유 권리와 철회 범위는 OPEN이며 권리 불명 결과는 새 공개를 막는 후보로 둔다. 승인본 정정은 기존 게시본을 조용히 덮어쓰지 않고 새 버전·검토 이력을 남긴다. 과거 승인자의 계정 종료가 과거 승인 이력을 자동 무효화하지는 않지만 새 게시에는 현재 권한이 필요하다.

생성 실패 시 수동 원고/요약/나눔지 제공을 유지한다. CHGO 장애가 이미 승인되고 현재 열람 권한이 유효한 설교의 제공을 막지 않는다. 직접 영상 호스팅/전용 구축은 별도 계약이며 저장 한도·요금·자동삭제 정책을 이번에 추가하지 않는다.

## Academy 참여에서 실천까지

| 업무 | 정본 | ChurchOS가 받거나 하는 범위 |
|---|---|---|
| 교회 도입 | 교회 연결 + Academy 등록 | 도입 선택/허용 참조. 개인 강제 등록 아님 |
| 과정/개설반/수강 | Academy | 계약된 과정/개설반ref와 동의된 본인 최소 수강 정보 |
| 현장 일정/출석 | ChurchOS | 허용 목적의 운영 사실만 Academy에 전달. 그 자체를 수료로 결정하지 않음 |
| 너랑나랑 활동 | 너랑나랑 | 허용된 초대/세션 최소 상태와 안전한 이동. 답변/서명 원문 수신 금지 |
| 생명일기 실천 | 생명일기 | 사용자 요청 일회용 이동. 작성 여부/날짜/회차/코칭 상태 수신 금지 |
| 평가·수료 | Academy | Academy 기준과 허용 표시 계약. 교회 출석/앱 복귀를 자동 완료로 쓰지 않음 |
| 코칭/개인 공유 | 각 기록 소유 제품 | 교회 관리자/강사 지정만으로 공유·코치 권한을 자동 부여하지 않음 |

교회가 Academy를 선택했어도 모든 교인을 수강생으로 만들지 않는다. 개인이 독립 수강하는 경로와 ChurchOS 교회 메뉴 노출은 별도다. Academy 미참여 교회의 기본 교회 기능·말씀·기도를 제한하지 않는다.

수료 후 너랑나랑·생명일기의 개인 실천은 제품 정책으로 지속할 수 있다. 수강 종료와 코치/공유 권한 종료·개인 기록 삭제는 서로 다르다. 재수강/재가입/교회 재도입 시 과거 역할·공유를 자동 복구하지 않는다. 강사에게 생명일기 작성 여부를 알려주는 우회 집계/완료 배지는 이번 범위에서 허용하지 않는다. 실제 수료 요건·외부 활동 확인 방법은 Academy 계약 OPEN이다.

CHGO는 Academy 교육 목표/개념을 연결할 수 있지만 교회 개인별 영적 점수·순위·성숙도·자동 봉사 배치의 근거를 만들지 않는다. 기존 공동체 집계는 별도 최소집단/억제/차분 방지 계약이며 10명만 충족하면 어떤 개인 자료도 수집 가능하다는 뜻이 아니다.

## 남은 승인/검증

실제 제공자 소스/API, 콘텐츠 권리, 엔진 정본 버전/근거 형식, 사람 승인 권한, 외부 처리/보유/삭제, 수강/수료 최소 필드, 교육 종료 후 코치 권한, 게시/철회/늦은 결과 경합의 계약이 필요하다. 이번에는 코드·DDL·scope를 만들거나 외부 서비스에 자료를 전송하지 않았다.
