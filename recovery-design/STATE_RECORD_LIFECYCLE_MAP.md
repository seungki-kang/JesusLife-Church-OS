## 목적별 계약 매개변수 — 숫자 미확정

| 기록 목적 | 필요한 기산 사건 | 아직 정해야 할 항목 | 삭제 전에 증명할 조건 |
|---|---|---|---|
| 일반 조회 투영 | 실제 접수 또는 실제 최종 확정 | 공개 차단 후 물리 삭제 완료 시한·백업 범위 | 삭제로 원본/중복 방지/미확정 조사를 오인하지 않음 |
| 접수/확인 ID 연결 | 실제 유효 접수 | 미확정 최대 보유·종결·뒤늦은 확정 연결·삭제 상한 | 매핑 손실/삭제 후 새 실행을 만들지 않음 |
| 중복 방지 | 기존 영수증 생성 및 계약된 실행 유효 구간 | 행 실제 보유/삭제·재사용 차단·복원 필터 수명 | 오래된 요청이 기록 없음 분기로 실행되지 않음 |
| 업무 원본 | 해당 업무의 목적/종료 사건 | 업무 종류별 수명·개인/공동/교회 귀속 | 당사자 탈퇴를 교회/타인 기록 포괄 삭제로 처리하지 않음 |
| 일반 감사/조사 | 실제 허용 행위 또는 조사 목적 개시/종결 | 목적별 상한·접근·예외·백업·삭제 증거 | 특정 정정/종료의 1년을 모든 감사에 확대하지 않음 |
| 기기 최소 참조 | 기기 최초 기록 및 합의된 정리 사건 | 로컬 상한·시계/복원·정리 실패·OS 백업 제외 | 삭제가 서버 취소·실패·재실행으로 바뀌지 않음 |
| 삭제/실행 재적용 근거 | 해당 삭제/확정 사건 | 다른 사본의 마지막 재등장 가능 구간과 최소 보호 수명 | 너무 먼저 지워 삭제 복원/중복 실행이 가능해지지 않음 |

미결을 영구 보유 허가로 쓰지 않는다. 보유기간을 정하지 않은 상태로 운영 출시하지 않는다. 서류·교인 정정·서비스/공통 탈퇴의 이미 합의한 1년·7일·30일은 기존 원문 범위만 유지한다.

## 장기 미확정의 모순 방지

공개 접수+168h가 지나도 실제 업무 결과를 거절/완료로 조작하지 않는다. 반대로 언제든 최종 확정될 수 있다는 이유로 모든 접수/원문을 무기한 보유하지 않는다. 담당/대행·조사 종결 증거·보유 상한·해결 불가 처리·필요한 예외를 함께 결정해야 한다. 안전한 최종 미반영 확정에 대한 증거가 없으면 기산점을 조작하지 않고 제한된 운영 확인으로 남긴다. 장기 미종결의 기간 정책은 여전히 OPEN이다.

## 복원 게이트

1. 복원 대상 공개·알림·업무 실행을 보류한다.
2. 최신 탈퇴/정지/소속/업무 권한·삭제·실행 확정·실행권 세대를 재적용한다.
3. 최초 실제 접수/확정/삭제 시각으로 기한을 판정한다. 복원 시각으로 초기화하지 않는다.
4. 원문/영수증/상태가 어긋나면 일괄 성공·거절·재실행하지 않고 대조한다.
5. 조회·쓰기·외부 발행을 각각 안전하게 재개할 수 있음을 검증한다.

이 순서는 설계 수용 조건이며 실제 복원 PASS가 아니다. 일반 DB 백업 복원이 성공했다는 과거 검사로 새 계약 준수를 승계하지 않는다.

## 이 묶음의 설계 인계 범위

요청 처리 분야의 상태/근거/조회/보유/복구 연결 초안을 한 묶음으로 구성했다. 미결 수치·DB 경합·실제 시각·호환 이행이 남으므로 구현 준비 완료가 아니다. 다음에는 이 미결표를 유지한 채 공통 로그인→교회 개설→교인 승인→역할 지정의 앱 흐름을 같은 형식으로 연결해 교회 기본 업무 설계를 넓힌다.
