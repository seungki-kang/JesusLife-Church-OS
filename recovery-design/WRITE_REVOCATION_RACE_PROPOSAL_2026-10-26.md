## 적용 범위

ChurchOS 일반 업무의 쓰기와 해당 업무 권한 해제에 한정한다. 가입 승인 결과 정정·마지막 관리자 보호·공통 계정 정지의 기존 정책을 대체하지 않는다. 기존 취소/수락 경합과 본인 요청 최소 상태 조회 합의도 유지한다. 이 파일은 부분 복원본에 추가하는 신규 명세이며 소실 원문의 복구가 아니다.

## 확정한 운영 결과 원칙

업무 쓰기와 권한 해제는 같은 권한 범위에 대해 서버에서 순서를 결정할 수 있어야 한다. 요청 도착·버튼 클릭·앱 표시·로그 시각의 빠름으로 결정하지 않는다. 최종 권한 판정과 저장이 분리돼 그 사이에 해제가 끼어들 수 없도록 하나의 일관된 확정 절차로 묶는다.

- 해제가 먼저 유효하게 확정되면 아직 확정되지 않은 이전 권한 기반 쓰기는 거절한다.
- 쓰기가 먼저 유효하게 확정되면 그 변경은 유지하며 해제는 이후 작업을 차단한다. 이전 쓰기를 자동 취소·삭제하지 않는다. 필요하면 현재 권한을 가진 담당자가 별도 정정 절차를 따른다.
- 확정되지 않은 트랜잭션은 선행 성공으로 인정하지 않는다. 롤백되면 업무 변경·성공 결과·알림 발행도 성공으로 남기지 않는다.
- 관리자는 해제 완료 확인을 받기 전에는 완료로 표시하지 않는다. 대기·통신 단절은 처리 상태 확인으로 안내하고 임의로 해제 성공을 추정하지 않는다.
- 권한 만료도 최종 권한 판정 지점에서 확인한다. 종료 경계와 같은 시각은 만료다. 장시간 대기한 요청은 대기 전 권한 판정만으로 저장할 수 없다.

## 서버 확정 명세 후보

1. 검증된 계정·교회·행위·대상으로 요청을 식별한다. 클라이언트가 전달한 역할이나 교회 이름을 권한 근거로 신뢰하지 않는다.
2. 같은 권한 범위의 쓰기와 해제를 직렬화하는 권한 잠금 또는 동등한 조건부 버전 제어를 적용한다. 업무 대상 버전과 권한 세대도 검증한다. 특정 DB 기법은 아직 선택하지 않는다.
3. 실행 시 최신 계정·소속·업무 권한·기간·대상 범위를 검증한다. 유효성 확인 불가는 성공으로 처리하지 않는다.
4. 업무 변경과 요청 결과·필요한 최소 감사 참조를 함께 확정한다. 커밋 전 외부 알림·이벤트를 발행하지 않는다. 알림이 필요하면 커밋된 발행 대기 기록을 사용하며 전달 시점의 공개 권한도 확인한다.
5. 해제는 권한 상태와 세대를 확정한 뒤 완료 응답한다. 해제 완료 이후 새로 확정되는 이전 권한 기반 업무가 없음을 보장하는 설계가 필요하다. 잠금 대기 중의 처리·타임아웃·복제 지연은 구현 전 검증 대상이다.

공통 계정 정지 등 외부 인증 상태와 로컬 트랜잭션을 원자적으로 묶었다고 가정하지 않는다. 그 경계의 최신성·전파·차단 계약은 별도 미결이며 연동 검증이 필요하다.

## 중복 요청과 결과 불명

- 동일 계정·교회·행위·대상·내용에 묶인 요청 식별자를 사용한다. 같은 식별자로 다른 내용을 보내면 거절한다. 식별자 형식과 보유 기간은 후속 계약에서 정한다.
- 응답이 끊겼다는 이유로 새 식별자의 같은 쓰기를 자동 제출하지 않는다. 먼저 기존 요청의 상태를 확인한다.
- 이미 확정된 같은 요청의 재시도는 다시 실행하지 않는다. 다만 결과 응답 내용은 현재 조회 권한으로 제한한다.
- 쓰기는 성공했어도 권한이 해제되면 본문·개인정보를 다시 제공하지 않는다. 계정과 교회 소속이 유효하면 합의된 본인 최소 상태 조회만 허용한다. 계정·소속이 무효하거나 확인 불가하면 요청 존재도 공개하지 않는다.
- 최종 상태 조회 168시간 만료를 업무 실패·실제 데이터 삭제·중복 방지 기록 삭제로 해석하지 않는다. 재실행 안전성이 확인되지 않으면 과거 요청을 신규 업무로 실행하지 않는다.
- 최초 결과 불명부터 해결되지 않으면 기존 24시간 내 수동 확인 이관 정책을 적용한다. 보안 이상은 즉시 조사하며 통신 재시도로 이 시간을 초기화하지 않는다.

## 앱 표시

| 상황 | 사용자 안내 |
|---|---|
| 해제가 먼저 확정 | 권한이 변경되어 처리하지 못했습니다. |
| 쓰기 확정, 이후 해제, 소속 유효 | 처리 완료 여부만 표시. 원문·변경 값 미표시 |
| 응답 단절, 상태 미확정 | 처리 결과 확인 중. 새 요청으로 자동 재실행 금지 |
| 소속·계정 유효성 확인 불가 | 인증·접근 확인 안내. 요청 존재나 본문 미표시 |
| 관리자 해제 응답 단절 | 해제 결과 확인 중. 완료로 단정하지 않음 |

정확한 HTTP 코드·오류 식별자·응답 필드·로그 필드는 아직 계약 후보이며 이 문서에서 확정하지 않는다.
