# 소개 철회 — T1 격리 실험 인계

[실험 명세](../LEADER_INTRO_T1_ISOLATED_EXPERIMENT_SPEC.md)와 [검증 계획](../LEADER_INTRO_POSTGRES_FINAL_TIME_VERIFICATION_PLAN.md)을 참고한다. 여기에는 실험 안내만 있다. 실행기는 [원본 r175 보존본과 그 별도 실행 파일](../README.md)의 같은 리비전을 사용한다. GitHub 소스 트리에서 ZIP 전용 실행기를 복제하지 않는다.

r175 Windows PowerShell·Docker·PostgreSQL 실제 실행과 운영 ACL·E03~E06은 NOT_RUN이다. 합성 E01/E02 보고서가 기본 검사를 통과해도 운영 권한이나 장애 복구가 검증된 것은 아니다. 검증된 최종 확정 시각을 얻는 방식은 실제 보고서 검토 전 미확정이다.
